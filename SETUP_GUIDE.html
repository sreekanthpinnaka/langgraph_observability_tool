Architecture: Decoupled by Design

┌───────────────────────────────────────┐ ┌──────────────────────────────────────────┐ │ FastAPI Backend (Port 8000, etc.) │ │ Standalone Server (.exe / Port 8765) │ │ │ │ │ │ ├── instrument_fastapi(...) │ HTTP │ ├── Ingestion API: /api/v1/traces │ │ ├── observe_graph(workflow) │ ─────────► │ ├── Storage: SQLite or Cloud SQL MySQL │ │ └── Async Background Exporter │ (Async) │ └── Live Dashboard: http://localhost:8765│ └───────────────────────────────────────┘ └──────────────────────────────────────────┘

Your client programs run independently. If the observability server is offline, your backend continues executing with zero latency and zero disruption.

Installing the Client SDK in Other Programs

Step 1: Install the Wheel or Package

The wheel package (.whl) is pre-compiled and can be installed in any Python environment (Python 3.9+).

Option A: Install using local wheel file (Recommended)
pip install dist/langgraph_observe-0.1.0-py3-none-any.whl
Option B: Install from source folder
pip install d:\observe
Option C: Add to requirements.txt
# In requirements.txt ./libs/langgraph_observe-0.1.0-py3-none-any.whl

Step 2: Instrument Your FastAPI Application

Only two lines are needed: call instrument_fastapi(app) and wrap your compiled LangGraph workflow with observe_graph(). 

from fastapi import FastAPI
from typing import TypedDict
from langgraph.graph import StateGraph, START, END

# 1. Import observability hooks
from langgraph_observe import instrument_fastapi, observe_graph

app = FastAPI(title="Payment & Order Service")

# 2. Point client to the running observability server
# (Use localhost:8765 if local, or http://<SERVER_IP>:8765 if on network)
instrument_fastapi(app, server_url="http://localhost:8765")

# 3. Define your LangGraph workflow
class OrderState(TypedDict):
    query: str
    response: str

builder = StateGraph(OrderState)

def process_order(state: OrderState) -> dict:
    return {"response": f"Processed order query: {state['query']}"}

builder.add_node("process", process_order)
builder.add_edge(START, "process")
builder.add_edge("process", END)

# 4. Wrap compiled graph with observe_graph
workflow = observe_graph(builder.compile(), name="OrderWorkflow")

# 5. Execute in your route
@app.post("/checkout")
async def checkout_endpoint(payload: dict):
    result = await workflow.ainvoke({"query": payload.get("query", ""), "response": ""})
    return result

Running & Distributing the Standalone Executable (.exe)

1. No Python Required

Anyone with a Windows machine can run the Observability Server & Dashboard without installing Python, pip, or virtual environments.

Files to distribute to teammates:
📁 MyObservabilityServer/
├── langgraph-observe.exe (The standalone server app, ~49 MB)
└── .env (Configuration file)

Both files are located in your dist/ directory. You can zip and send this folder directly.

2. Database Configuration (.env)

Before launching, open .env in Notepad to choose the database storage:

Option A: Shared Cloud SQL (MySQL) - Ideal for teams
DATABASE_URL="mysql+pymysql://user:password@cloud-sql-host:3306/observe"
Option B: Local SQLite - Ideal for solo/offline use
# Simply comment out or clear DATABASE_URL to automatically use local observe.db

3. One-Click Launch Walkthrough

1
Double-click langgraph-observe.exe

A console window opens and displays the current database configuration.

2
Database URL Prompt

Press Enter to keep the configured database, or paste a new database URL and press Enter.

3
Live URLs & Browser Auto-Launch

The server starts and automatically launches your web browser to:

👉 Dashboard: http://127.0.0.1:8765/
👉 Ingestion API: http://127.0.0.1:8765/api/v1/traces
4
Exit Protection

If stopped (e.g. via Ctrl+C) or if an error occurs, it prompts Press Enter to exit... so the console does not flash and vanish.

4. Optional Command Line Usage

For automated environments or scripts, the executable accepts command-line arguments:

# Custom port
.\langgraph-observe.exe server --port 9000
# Run without automatically opening the browser
.\langgraph-observe.exe server --no-browser
# Explicit database URL
.\langgraph-observe.exe server --db-url "mysql+pymysql://user:pass@host:3306/db"

Frequently Asked Questions

Can client apps on different machines connect to this server?

Yes! In your client app, replace http://localhost:8765 with the IP or hostname of the machine running the `.exe` (e.g. http://192.168.1.50:8765). If needed, run the `.exe` with --host 0.0.0.0 to allow external network connections.

How do I recompile the executable after making code changes?

Simply run py build_exe.py in the repository root. It compiles everything into dist/langgraph-observe.exe automatically.
